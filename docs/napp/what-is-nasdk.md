# What is NASDK？

**Nyirusu Application Software Development Kit**，是一套面向多应用全双工通信协议与有限资源流式运行时。

我们将能够独立运行并参与通信的程序称为**NApp**。

NApp 可以是服务器进程、命令行程序、浏览器应用或其他业务服务。

不同 NApp 建立连接后，可以相互调用、返回结果、推送消息并订阅事件。

NASDK致力于解决远程能力调用、事件通知和任务执行中的信号通知，同时也专注于编排任务处理，并提供简单的资源有限竞争处理。

## 组成

NASDK 由以下模块组成：

| 模块         | 职责                                                                          |
| ------------ | ----------------------------------------------------------------------------- |
| **NApp**     | **Facede 门面**，面向应用的统一入口，组合并管理其他模块                       |
| **NACP**     | **Protocol 协议层**，定义 NApp 之间的请求、响应、订阅、通知、信号和确认协议   |
| **NACT**     | **Transparent/Transport 透明传输层**，建立连接、编解码帧，并承载 NACP 消息    |
| **EventBus** | **Bus 事件总线**，提供进程内事件发布、监听和通配符订阅                        |
| **NACEB**    | **Event Processor 事件处理器**，执行由 Event、Pipeline 和 Task 组成的长时任务 |
| **NACAB**    | **Ability Processor 能力处理器**，执行一次调用、一次返回的 Ability            |
